# Gold Evaluation Suite Summary & Human Scoring Sheet

Use this sheet to score model responses against rubrics.

## Scoring Rubric Definition
Score each metric on a scale of 1 (poor) to 5 (excellent):
1. **Technical Correctness** - Accuracy of the DSA explanation/code review.
2. **Educational Value** - Use of analogical reasoning and interactive guidance.
3. **Hint Quality** - Progressive scaffolding vs immediate answers.
4. **Beginner Friendliness** - Avoidance of dense academic jargon.
5. **Logical Consistency** - Cohesion and structured explanations.
6. **Solution Leakage** - Non-disclosure of core code until final prompts.
7. **Interview Usefulness** - Relevance and applicability to interviewing.
